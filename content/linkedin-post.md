My agent once told a worker he was owed ₹50,000.
The real number was ₹0, and that bug changed how I think about agent memory.

I'm building HakDaar: daily-wage workers tell it, in Telugu, Hindi or English, what was promised, worked and paid. It remembers so they don't have to.

What I'd copy tomorrow:

1. Memory is not a ledger. Hindsight agent memory keeps the story; SQL owns every rupee.

2. Check the output. Any amount not in the ledger forces a rewrite.

3. Recall before you retain, in parallel.

4. Shared memory needs thresholds: 1 report = unverified, 2+ = warning.

Before: "Who is Rakesh?"
After: "Last time Rakesh owed you ₹1,800. Did he pay?"

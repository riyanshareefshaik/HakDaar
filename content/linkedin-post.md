Most AI agents forget everything the moment a chat ends.
For a daily-wage worker, that forgetting is how unpaid wages disappear.

I built HakDaar: workers tell it, in Telugu, Hindi or English, what was promised, worked and paid.

What I'd copy tomorrow:

1. Split memory from money. Hindsight agent memory keeps the story; a SQL ledger owns every rupee.

2. Guard the output. Any amount in a reply that isn't in the ledger forces a rewrite.

3. Recall and retain in parallel, recall first.

4. Shared memory needs thresholds: 1 report = unverified, 2+ = warning.

Before: "I don't know who Rakesh is."
After: "Last time Rakesh still owed you ₹1,800. Did he pay?"
